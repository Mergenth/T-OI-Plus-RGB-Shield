T-OI Plus + LD2410C Radar-Shield für Home-Assistant

Diese Seite flasht eine ESPHome-Firmware auf ein LILYGO T-OI Plus (ESP32-C3) mit angeschlossenem 24-GHz-Radarsensor LD2410C. Der Sensor erscheint in Home Assistant als Anwesenheitsmelder.

Weitere Seiten: 8x8 RGB Shield (drei Programme) · 1-Button Shield für Home-Assistant

Firmware flashen

Dieser Browser unterstützt Web Serial nicht. Bitte Chrome oder Edge am Desktop verwenden. Diese Seite muss über HTTPS aufgerufen werden.

Ablauf

  1. T-OI Plus per USB anschließen und oben auf „Firmware flashen“ klicken, COM-Port wählen. Falls die Verbindung scheitert: BOOT gedrückt halten, RST kurz drücken, BOOT loslassen und erneut versuchen.
  2. Nach dem Flashen fragt der Dialog nach dem WLAN (Improv). SSID und Passwort eingeben; alternativ verbindet man sich mit dem Access Point t-oi-plus-ld2410c und nutzt das Captive Portal.
  3. Home Assistant findet das Gerät automatisch über die ESPHome-Integration (Einstellungen → Geräte & Dienste → Entdeckt → ESPHome). Sonst „ESPHome“ hinzufügen und die IP-Adresse eintragen.
  4. Folgende Entitäten stehen bereit: Presence, Moving Target, Still Target sowie Distanzen (Moving, Still, Detection) und Energiewerte (Moving, Still).
