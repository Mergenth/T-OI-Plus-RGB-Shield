T-OI Plus + 8x8 RGB Shield

Flasht die LED-Testfirmware (64x WS2812B an GPIO8) direkt aus dem Browser auf ein LILYGO T-OI Plus (ESP32-C3).

Bitte Chrome oder Edge am Desktop verwenden (Web Serial wird benoetigt). Diese Seite muss ueber HTTPS geoeffnet werden.

Vorher

  1. Board per USB anschliessen.
  2. BOOT gedrueckt halten, kurz RST druecken, BOOT loslassen (Download-Modus).
  3. Auf „Firmware installieren“ klicken und den COM-Port des Boards waehlen.
  4. Nach dem Flashen einmal kurz RST druecken.
