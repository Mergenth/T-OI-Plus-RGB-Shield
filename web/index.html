T-OI Plus + 8x8 RGB Shield

Flasht eine Firmware direkt aus dem Browser auf ein LILYGO T-OI Plus (ESP32-C3) mit WEMOS 8x8 RGB Shield (64x WS2812B an GPIO8). Zur Auswahl stehen drei Programme:

1. Farbtest

Alle 64 LEDs leuchten nacheinander rot, grün, blau und weiß, danach läuft ein blauer Punkt als Lauflicht über das Shield.

Bitte Chrome oder Edge am Desktop verwenden (Web Serial wird benötigt). Diese Seite muss über HTTPS geöffnet werden.

2. Laufschrift „Carenuity“

Der Name Carenuity läuft in Blau von rechts nach links über die 8x8-Matrix.

Bitte Chrome oder Edge am Desktop verwenden (Web Serial wird benötigt). Diese Seite muss über HTTPS geöffnet werden.

3. Regenbogen

Ein weicher Regenbogen-Farbverlauf wandert diagonal über alle 64 LEDs.

Bitte Chrome oder Edge am Desktop verwenden (Web Serial wird benötigt). Diese Seite muss über HTTPS geöffnet werden.

Vorher

  1. Board per USB anschließen.
  2. BOOT gedrückt halten, kurz RST drücken, BOOT loslassen (Download-Modus).
  3. Auf den gewünschten Knopf klicken und den COM-Port des Boards wählen.
  4. Nach dem Flashen einmal kurz RST drücken.
